# Fundermax Logistics ERP

A cloud-native, mobile-first enterprise resource planning system designed to manage high-value physical logistics, cross-department tracking, and automated supplier communication.

## Tech Stack
- **Frontend & Backend:** Next.js (App Router, Serverless API Routes)
- **Database:** SQLite (Hosted at the Edge via Turso / libSQL)
- **File & Media Storage:** Cloudflare R2 (S3-compatible object storage for PDFs and images)
- **Styling & UI:** Tailwind CSS (Optimized for mobile surveillance dashboards)
- **Automation:** Integrated WhatsApp API hooks for automated vendor receipt and invoice dispatch.

## Key Features
- Real-time tracking of high-value inventory panels.
- Serverless architecture designed to bypass local ISP and infrastructure limitations.
- Automated dynamic PDF generation and instant WhatsApp routing.
- Role-based visibility separating generic ledger accounting from physical logistics.
