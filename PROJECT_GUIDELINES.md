# Project Guidelines & Rules

## 1. Strict Emoji Rule: No Sparkle Emojis
- **NEVER** use or add any sparkle emojis (`✨`, `❇️`, `✳️`, `🌟`, `💫`, or any glitter/magic stars) anywhere in this repository (UI, components, modals, prints, logs, buttons, titles, or text).
- **NEVER** import or introduce `Sparkles`, `Sparkle`, or related magic/glitter icons from `lucide-react`.
- Always maintain clean, professional, ink-friendly warehouse styling. Use clean functional icons (e.g. `Layers`, `PackageCheck`, `Printer`, `Search`) or clear domain emojis (`🪵` for wood panels, `📦` for orders).
